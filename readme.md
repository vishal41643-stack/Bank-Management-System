# Banking Management System

This is a simple Banking Management System built using C++. I created this project to practice object-oriented programming, classes, file handling, and basic banking operations.

The application allows users to create and manage accounts, check balances, deposit money, and withdraw money. Account information is stored in a file so that the data can be saved between program runs.

## Technologies Used
- C++
- Object-Oriented Programming (OOP)
- File Handling
- Standard Template Library (STL)

## Features
- Create and manage bank accounts
- Deposit and withdraw money
- View account balances
- Store account information using file handling

This is a learning project, and I plan to improve its structure and add more features as I continue learning C++.
